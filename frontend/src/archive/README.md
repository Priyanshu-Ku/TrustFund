# Archived Phase 1 Mock Services

These services (`donationService.js` and `expenseService.js`) were the initial in-memory mock data services used during Phase 1 frontend development before the Ethereum smart contract was deployed.

In Phase 4, they were completely superseded by `src/services/blockchain.js`, which interfaces directly with the deployed `DonationTracker.sol` smart contract on Ethereum Sepolia using Ethers.js.

They are preserved here for historical code review and project evolution demonstration.
