About The Project

Eliminating Blind Faith with Transparent Blockchain Tech

Traditional charities lack transparent, granular tracking of how donated funds are spent. TrustFund resolves this by combining Ethereum smart contracts for tamper-proof transaction recording and machine learning algorithms to detect anomalous expense reports automatically.
